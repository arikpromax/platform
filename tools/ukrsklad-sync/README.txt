ОБМІН УКРСКЛАД <-> САЙТ JUST SHOP

Програма стоїть на комп'ютері з УкрСкладом. До бази підключається локально,
як ваша утиліта, а з сайтом говорить сама по https. Базу в інтернет відкривати
не треба. Кожні 2 хвилини (можна змінити):

  1. Забирає з сайту нові замовлення й робить на них видаткові за вашою
     документацією: шапка VNAKL -> рядки VNAKL_ -> назви з TOVAR_NAME -> суми.
     Клієнт — один, «Інтернет-магазин». Номер документа — дата й час
     замовлення + номер замовлення на сайті, напр. 251007-1432-0014. Номер
     завжди той самий для того самого замовлення: якщо зв'язок обірветься,
     документ не задвоїться.
  2. Перед видатковою перевіряє, чи є товар в УкрСкладі. Немає (щойно продали
     в магазині) — документ не робить, а сайт пише власнику в Telegram. Довезуть
     товар — проведе сама.
  3. Скасоване чи повернене замовлення, на яке вже є видаткова, —
     документ повернення.
  4. Читає залишки й ціни і шле на сайт те, що змінилось. Раз на добу
     (після 3:00) — повний перелік: чого в ньому немає, на сайті стає 0.
     Новий товар з'являється на сайті сам.

Ключ кожного товару — ID з УкрСкладу (TOVAR_NAME.NUM). Усі 578 ID із вашої
таблиці вже прив'язані на сайті до своїх розмірів.


ЩО ПОТРІБНО

  - Java 8 або новіша (java -version). Для Java 8 — оновлення не старше 2020 р.,
    інакше може не прийняти сертифікат сайту.
  - Драйвер Firebird для Java (Jaybird) — той самий, що для вашої утиліти.
    Покласти в теку lib.


НАЛАШТУВАННЯ

  1. Скопіюйте всю теку на комп'ютер з УкрСкладом, напр. C:\UkrSkladSync
  2. Покладіть jar-файли Jaybird у lib
  3. Скопіюйте ukrsklad-sync.ini.example як ukrsklad-sync.ini і заповніть:
       [site] key           — ключ обміну (власник передасть окремо)
       [database]           — як у вашому order.ini
       [ukrsklad]           — firma_id, sklad_id, client_id, doc_user_id
       [documents] return_* — таблиці документа повернення
  4. У stock.sql напишіть запит, звідки брати залишки й ціни
     (які колонки потрібні — написано в самому файлі)


ПЕРЕВІРКА (нічого не змінює)

  run.bat --check
     Покаже: чи підключилась до бази, скільки товарів прочитала (і перші 5),
     чи сайт прийняв ключ і скільки є нових замовлень.

  Потім, лишивши в ini  dry = true:
  run.bat --once
     Один прохід у пробному режимі: у журналі видно, які видаткові створила б
     і що сайт змінив би в залишках. Ні в УкрСклад, ні на сайті нічого не пишеться.

  Коли все сходиться — dry = false, оформлюємо на сайті тестове замовлення,
  run.bat --once і дивимось, що в УкрСкладі з'явилась видаткова.


РОБОТА

  run.bat — працює безперервно, поки відкрите вікно. Щоб запускалась сама,
  додайте run.bat в автозавантаження Windows або в Планувальник завдань
  («під час входу в систему»). Друга копія не запуститься — задвоєння не буде.

  Журнал — ukrsklad-sync.log поруч із програмою. Якщо щось не так, перешліть
  його нам.

  Вимкнений комп'ютер — не страшно: замовлення дочекаються на сайті, а товар
  під них на сайті вже притриманий, подвійного продажу не буде.
